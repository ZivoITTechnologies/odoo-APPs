Get started in 5 steps

  1. Install Retail LMS and open Configuration > Settings: set your brand, sector and market, and optionally connect an AI provider.
  2. Add regions and stores and assign store managers.
  3. Add learners (or create them from Employees) and click Grant Learning Access.
  4. Create product knowledge cards and click AI: Build Micro-course.
  5. Build or AI-generate learning paths, tick Auto-assign and Publish. Staff open /my/learning on their phones.
