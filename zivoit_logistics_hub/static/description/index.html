ZivoIT Logistics Hub

One Odoo app for every courier, with AI that picks the right one and shows how much you save

Connect UPS, FedEx, DHL Express, USPS, Aramex, Shiprocket, Delhivery, Ekart, DTDC, Blue Dart, Xpressbees, Shree Maruti and any courier with a REST API from a single app. Compare every rate, ship with the cheapest courier that still arrives on time, print end-of-day manifests, run a branded returns portal and audit every carrier invoice, all inside Odoo.

Why you need this module

Too many courier panels

Stop copying orders into Shiprocket, Delhivery and DTDC portals. Book every courier from the Odoo delivery order.

COD orders coming back

An RTO risk score with reasons flags risky Cash on Delivery orders before they ship, and can hold them for you.

Guessing the courier

AI ranks every courier by price, speed and the delivered and RTO rate it achieved on that PIN code in your own history.

Failed deliveries pile up

The NDR queue explains each failed attempt, suggests the next action and drafts the message to the customer.

Paying too much for shipping

Every booking compares all couriers, respects the delivery date and records the money saved. Reports show the total.

Returns handled by email

Customers request returns on a branded page. Approved returns create the return transfer and book the reverse pickup.

Carrier invoices never checked

Import the carrier invoice or COD remittance file: overcharges, weight disputes and short COD payments are flagged.

Slow dispatch desk

Scan to ship, bulk labels and end-of-day manifests with automatic pickup requests keep the packing table moving.

Terms used on this page: COD = cash on delivery | RTO = return to origin (the parcel comes back undelivered) | NDR = non-delivery report (a failed delivery attempt) | AWB = air waybill (the courier tracking number) | UTR = bank reference of a COD payment | PIN code = Indian postal code

Get started in 5 steps

  1. Install the app. Inventory, Sales and Delivery are installed with it automatically.
  2. Go to Logistics Hub > Configuration > Carrier Accounts. Add your couriers and click Test Connection.
  3. Create a delivery method of type "ZivoIT Logistics Hub", choose AI Best, cheapest on time or allocation rules, and set insurance if you need it.
  4. In Inventory > Configuration > Operation Types > Delivery Orders, enable "Print Label".
  5. Validate a delivery order: the courier is booked, the label is attached and tracking starts.

Try everything first with the built-in ZivoIT Sandbox Courier. It needs no credentials.
