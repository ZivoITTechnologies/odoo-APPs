# ZivoIT EduAgent AI (Odoo 19)

Everything for this module lives in this one folder.

| What | Where |
| --- | --- |
| Odoo module code | `models/`, `views/`, `controllers/`, `wizard/`, `security/`, `data/`, `static/src/` |
| Automated tests (36) | `tests/` - run with `--test-enable --test-tags=/zivoit_eduagent_ai` |
| App Store cover (1568x784) | `static/description/banner.png` |
| App Store description | `static/description/index.html` |
| Screenshots (28) | `static/description/screenshots/` |
| Description preview (PDF) | `static/description/description_preview.pdf` |
| App icon | `static/description/icon.png` |

Install: copy this folder into your addons path, update the apps list, install "ZivoIT EduAgent AI".
Then EduAgent AI > Configuration > AI Providers: add your key and click "Set as Company Default".
