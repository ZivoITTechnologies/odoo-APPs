Security by design

  • OAuth 2.1 with mandatory PKCE S256, exact redirect-URI matching, single-use codes valid 10 minutes, refresh-token rotation.
  • Only hashes of codes, tokens and secrets are stored.
  • Consent page protected against clickjacking and CSRF; it shows the app's return address.
  • Removing a user's AI right or pausing the connector cuts access immediately.
  • Every call runs through the Odoo ORM as the person or integration user: access rights and record rules apply.
  • Security and technical models are always blocked; passwords, keys, tokens and binaries are never exposed.
  • Origin validation, IP allow-list, rate limit, expiry and kill switch.
  • Each tool call runs in a savepoint: a failing call never leaves partial changes.

Frequently asked questions

Do I need AnythingMCP or any other service?

No. The app contains its own MCP server and its own OAuth 2.1 sign-in, so Claude, ChatGPT, Cursor and Claude Code connect directly to https://your-odoo/mcp. Gateways such as AnythingMCP are still supported with API keys.

Which Odoo apps are required?

None besides Odoo itself (base, web, mail). Report tools appear automatically when the matching app is installed: Invoicing/Accounting, Sales, Purchase, Inventory, CRM. Search and grouping tools work on any model, including custom ones.

What can the assistant see?

With Sign in with Odoo, exactly what the signed-in person can see in Odoo (access rights and record rules), limited to the connector's companies and models. Passwords, keys, tokens and binary fields are always hidden and security models are always blocked.

Can the AI change my data?

Not by default: connectors are read-only. Writing needs a Read & write connector, enabled write tools and Create or Update ticked per model. There is no delete tool.

How do I disconnect an assistant?

Each person sees their sessions under My AI Sessions and can disconnect them; administrators see every session and every registered application, and can turn sign-in off in Settings.

What does my Odoo need?

Odoo 19 Community or Enterprise on Odoo.sh or your own server, reachable on a public HTTPS address so cloud AI apps can call it. Odoo Online does not accept third-party apps.

Is it standards-compliant?

Yes: MCP Streamable HTTP (2024-11-05 to 2025-11-25), OAuth 2.1 with PKCE S256, RFC 9728 protected-resource metadata, RFC 8414 server metadata, RFC 7591 dynamic registration, RFC 7009 revocation and RFC 9207 issuer identification. Tested with the official MCP Python SDK and TypeScript client.
