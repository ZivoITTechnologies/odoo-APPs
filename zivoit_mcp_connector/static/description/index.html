Connected in five steps

STEP 1

Install

Install the app on Odoo 19. A ready-to-use, read-only connector named Claude & ChatGPT - Sign in with Odoo is created automatically.

STEP 2

Give access

Administrators can connect straight away. Give other people the AI Connector / User access right.

STEP 3

Paste the URL

In Claude open Settings > Connectors > Add custom connector and enter https://your-odoo/mcp. ChatGPT, Cursor and Claude Code work the same way.

STEP 4

Sign in

The AI app opens the Odoo login and consent page. Click Allow access. There is no key to copy and no middleware.

STEP 5

Ask

For example: "What are this month's sales by salesperson, and which customer invoices are overdue?" Every call is recorded in the audit log.

Security by design

  • OAuth 2.1 with mandatory PKCE S256, exact redirect URI matching, single-use codes valid for 10 minutes and refresh token rotation.
  • Only hashes of codes, tokens and secrets are stored.
  • The consent page is protected against clickjacking and CSRF and shows the return address of the app.
  • Removing the AI access right of a user, or pausing the connector, stops access immediately.
  • Every call runs through the Odoo ORM as the person or integration user, so access rights and record rules apply.
  • Security and technical models are always blocked; passwords, keys, tokens and binary data are never exposed.
  • Origin validation, IP allow-list, rate limit, expiry date and an emergency switch.
  • Each tool call runs in a savepoint, so a failing call never leaves partial changes.

Frequently asked questions

Do I need AnythingMCP or any other service?

No. The app contains its own MCP server and its own OAuth 2.1 sign-in, so Claude, ChatGPT, Cursor and Claude Code connect directly to https://your-odoo/mcp. Gateways such as AnythingMCP are still supported with API keys.

Which Odoo apps are required?

None besides Odoo itself (base, web and mail). Report tools appear automatically when the matching app is installed: Invoicing or Accounting, Sales, Purchase, Inventory and CRM. The search and grouping tools work on any model, including custom ones.

What can the assistant see?

With Sign in with Odoo, exactly what the signed-in person can see in Odoo (access rights and record rules), limited to the companies and models of the connector. Passwords, keys, tokens and binary fields are always hidden, and security models are always blocked.

Can the AI change my data?

Not by default: connectors are read-only. Writing needs a read and write connector, enabled write tools and Create or Update permission on each model. There is no delete tool.

How do I disconnect an assistant?

Each person sees their sessions under My AI Sessions and can disconnect them. Administrators see every session and every registered application, and can turn sign-in off in Settings.

What does my Odoo need?

Odoo 19 Community or Enterprise on Odoo.sh or your own server, reachable on a public HTTPS address so cloud AI apps can call it. Odoo Online does not accept third-party apps.

Is it standards compliant?

Yes: MCP Streamable HTTP (protocol versions 2024-11-05 to 2025-11-25), OAuth 2.1 with PKCE S256, RFC 9728 protected resource metadata, RFC 8414 server metadata, RFC 7591 dynamic registration, RFC 7009 revocation and RFC 9207 issuer identification.

Requirements
